定制键盘说明

用一小段 JSON，把常用符号、快捷键、Vim 命令做成自己的键盘页面。

是什么

定制键盘是符号面板里的一个专属页面：你定义哪些键、每个键按下去做什么。适合放常用符号、终端 / Vim 快捷键、单位、邮箱后缀这类高频短内容。数据只保存在本机，随备份导出。

入口有两处：

  • 系统设置 → Feelime 设置 → 键盘与输入 → 定制键盘
  • 键盘上：长按左上角 F 图标打开快捷设置 → 定制键盘（这里有「插入模板」按钮，一键填入示例）

JSON 格式

整份配置是一个对象：version 固定为 1；rows 是键的行数组，最多 3 行，每行键数不限（放不下可以在行内左右拖动）。

{
  "version": 1,
  "rows": [
    [
      { "t": "Esc",  "tap": "[esc]",            "note": "Vim / 终端 Esc" },
      { "t": ":w",   "tap": ":w[enter]",        "note": "Vim 保存" },
      { "t": "保存", "tap": "[ctrl+s]",          "note": "常见保存快捷键" }
    ],
    [],
    []
  ]
}
字段含义限制
t键面上显示的文字最多 12 个字符
tap按下这个键时发生什么（见下面的语法）最多 128 个字符、16 个动作步
note长按这个键时弹出的说明，可省略最多 60 个字符

全部键加起来最多 100 个。空行可以留着，不影响。

tap 怎么写

tap 里写什么，按键就输入什么；用方括号表示特殊按键，两者可以混着写：

  • "tap": "→" —— 直接上屏一个箭头
  • "tap": "[esc]" —— 发一个 Esc 键
  • "tap": ":w[enter]" —— 先打出 :w，再按回车
  • "tap": "[esc]ggVGD" —— 先 Esc，再依次按 g g V G D（Vim 全文缩进）
  • "tap": "[ctrl+s]" —— 组合键：Ctrl 和 S 一起按

组合键的修饰键有 ctrl / alt / shift / win（也叫 meta），用 + 连接，可以叠：[ctrl+shift+t]。

特殊键写法
Esc / Tab / 回车 / 空格[esc] [tab] [enter] [space]
删除[bs]（退格）[backspace] [del]
方向键[left] [right] [up] [down]
Home / End / 翻页[home] [end] [pgup] [pgdn]
功能键[f1] … [f12]
组合键[ctrl+s] [alt+tab] [ctrl+shift+t] …

一个实用示例

写邮件常用的符号和结尾用语：

{
  "version": 1,
  "rows": [
    [
      { "t": "，", "tap": "，" }, { "t": "。", "tap": "。" },
      { "t": "！", "tap": "！" }, { "t": "？", "tap": "？" },
      { "t": "、", "tap": "、" }, { "t": "；", "tap": "；" }
    ],
    [
      { "t": "①", "tap": "①" }, { "t": "②", "tap": "②" }, { "t": "③", "tap": "③" },
      { "t": "℃", "tap": "℃" }, { "t": "±", "tap": "±" }, { "t": "×", "tap": "×" }
    ],
    [
      { "t": "邮箱", "tap": "@gmail.com", "note": "补全邮箱后缀" },
      { "t": "谢谢", "tap": "谢谢！", "note": "邮件结尾" }
    ]
  ]
}

粘贴保存后立即生效，不需要重启键盘。想恢复默认，清空 JSON 保存即可。

常见问题

  • 提示格式不正确？JSON 要求双引号、最后一项后面不能有多余逗号。先点「插入模板」再照着改，最不容易错。
  • 一行放太多键会怎样？行内可以左右拖动查看，不会挤坏布局。
  • 组合键在哪个 app 都能用吗？取决于那个 app 是否响应这个快捷键，键盘只负责如实发送。
